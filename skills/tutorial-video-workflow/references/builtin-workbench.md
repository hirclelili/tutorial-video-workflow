# 内置粗剪与逐字精剪工作台

## 定位

使用 Skill 自带的固定工作台完成自动粗剪之后的人工检查。不要每个项目临时生成网页，也不要要求用户安装 OpenChatCut。工作台只处理前期剪辑，不实现复杂动效、调色、花字、关键帧或高级混音。

## 数据与安全

- 固定前端位于 `assets/workbench/`。
- 项目数据位于 `<项目>/workbench/project.json`。
- 自动保存前把旧状态复制到 `<项目>/workbench/revisions/`。
- 媒体通过只读本地接口加载；不上传素材，不修改源文件。
- 删除只是设置非破坏性状态；恢复、撤销和重做必须可用。
- 逐字删除范围同时影响实时预览和审片导出。
- 初始视频和音频各保持一个连续片段；字幕可以按句分段。仅在真实删除或用户手动拆分处产生媒体切点。

## 使用顺序

1. 使用带字级时间戳的转写创建工作台项目。
2. 启动本地服务并向用户提供可点击地址。
3. 用户先检查自动粗剪，再手动删除、恢复、拆分或排序片段。
4. 用户通过逐字稿精确删除或恢复口播，并修改字幕文本。
5. 工作台持续自动保存；用户可以导出当前审片 MP4。
6. 用户点击“确认当前剪辑”。Codex读取确认版本，转换为统一时间线。
7. 用户点击“导出剪映工程”时，工作台检查原生模板和兼容导出器；缺失时保存导出请求并给出明确提示，条件齐全后才生成工程包。

## 限制

第一版以一个主视频及其音频为核心。辅助录屏或 B-roll 可以进入基础视频轨，但不要在没有完成真实预览验证时声称多机位合成可用。审片导出需要 FFmpeg/ffprobe；编辑和自动保存本身只需要 Python 3 与浏览器。
